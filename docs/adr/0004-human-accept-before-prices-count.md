# No invoice counts until a person accepts it

Extracted invoices stay drafts until a member of the venue reviews and accepts them; only accepted invoices create price points, alerts and margin changes. We chose this over auto-accepting "confident" extractions because a single misread price (a dropped decimal comma, a wrong product match) would distort costs and margins silently, and the venue would stop trusting every number. The review screen is designed to make accepting a clean invoice take seconds. Auto-accept is to be reconsidered only with accuracy data from the pilot.
